# Compass

查询 A 股公司的 F10 基本信息、近期日线行情和关联板块资讯，并维护一份自选。自选里每只股票一张卡片，看近期业绩、资金、股东人数，以及这段涨跌相对申万行业的位置。

## 运行

需要 Node.js 20 或更新版本。

```bash
cp .env.example .env
```

在 `.env` 里填写 `TUSHARE_TOKEN`。Token 从 [Tushare Pro](https://tushare.pro) 个人主页获取。没有 Token 时，F10 资料仍然可以查询。

```bash
npm start
```

浏览器打开 <http://localhost:3000>。

在「自选」输入 `600519` 或「贵州茅台」，点「加入」。名称不唯一时先选择一家。可以新建分组，把已录入的股票挪进去。勾选要看的公司后点「分析所选」，才会拉近期变化和中线；同时最多分析 12 只。列表保存在当前浏览器。也可以在「查询公司」里打开 F10 后点「加入自选」。

查询单家公司时，页面展示代码、简称、全称、行业、上市日期、主营业务、公司简介、注册地、法人、联系方式、公司网站，以及近 60 个交易日 K 线、重要交易日、关联板块和近 3 日板块快讯。名称不唯一时会先列出候选公司。例如输入「平安」，再选择「中国平安」或「平安银行」。

```bash
npm test
```

## 数据来源

公司资料来自东方财富数据中心公开接口 `RPT_F10_BASIC_ORGINFO`（`https://datacenter.eastmoney.com/securities/api/data/v1/get`，`source=HSF10`）。

按简称或全称检索时，会同时查询该接口的精确名称，并用东方财富搜索建议接口（`https://searchadapter.eastmoney.com/api/suggest/get`）补全简称。行业优先用东方财富行业分类，没有时用证监会行业。

日线、关联板块和板块资讯来自 [Tushare Pro](https://tushare.pro) HTTP 接口 `https://api.tushare.pro`：

- 日线：`daily`，未复权。页面保留近 60 个交易日，并标出涨停、跌停、大涨大跌、放量和阶段新高、新低。
- 关联板块：优先 `concept_detail`。取不到时用 `ths_member` 和 `ths_index`。
- 板块资讯：`news`，来源为财联社和东方财富，按板块名称匹配近 3 日标题。

`daily` 大约需要 120 积分。同花顺板块接口积分更高。`news` 需要单独开通「新闻资讯」权限。接口不可用时，页面会保留已经取到的部分，并说明原因。

自选卡片使用这些 Tushare 接口：

- 业绩：`forecast`、`express`，缺的营收、归母净利、ROE 同比用 `fina_indicator`。同一报告期优先快报；更新的报告期仍显示预告里的净利变动区间。
- 资金：`moneyflow` 近 5 个交易日大单与特大单净额，`margin_detail` 的融资余额相对 5 个交易日前的变化，近 7 个交易日的 `top_list` 或 `block_trade`。
- 股东：`stk_holdernumber` 最新户数相对上一期，`fund_portfolio` 最近两期公募持仓只数和占流通比，并按持仓市值列出基金名称、占流通和占基金比，默认前 6 只，其余折叠。`fund_basic` 补基金简称。`stk_surv` 近一年机构调研次数，默认列出最近 6 次的机构和要点，其余折叠。
- 位置：`daily` 近 20 个交易日涨跌幅，减去 `index_member_all` 给出的申万行业在 `index_daily` 里的同期涨跌幅。二级行业没有指数行情时，改用一级。

每张卡片下面另有一块中线，只看最近一年：周线高低点和支撑压力、20 周均线、市值与这一年的估值分位、低市盈率是否真便宜、近 1 年相对行业、业绩是否拐头、近 20/60 日资金、公募持仓和机构调研、近 7 个交易日龙虎榜，以及未来两季解禁。反证里会看近一年涨停、炸板和连板：经常涨停更像题材票。真便宜要求收入和净利同向、净利增速没有明显放缓；有卖方下一期净利润时，会再算一遍远期市盈率。结论分成高、中、低，用来区分反弹和反转的证据强弱。

这些接口按 5000 积分调用。公募持仓、机构调研和涨停炸板需要 5000 档。行情、自选和中线每次都有次数上限，同一只股票几分钟内直接用刚才的结果；同时进行的查询也有上限。内存里的接口缓存有固定容量，过期和最旧的记录会被清掉。没有 `TUSHARE_TOKEN` 时，自选卡片会提示先配置。

资料仅供查阅，不构成投资建议。
